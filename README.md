# modern-web-development

## Лабораторная работа №1 — статичная страница-визитка

Одностраничный сайт-визитка, свёрстанный на чистом HTML5 и CSS3 (без сборщиков и фреймворков). Реализованы семантическая разметка, адаптивный макет на Flexbox/Grid с тремя брейкпоинтами (mobile / tablet / desktop) и мобильное бургер-меню на минимальном ванильном JS.

### Структура проекта

```
index.html
css/
  styles.css
js/
  script.js
images/
README.md
.gitignore
```
